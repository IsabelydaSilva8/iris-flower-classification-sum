#Classificação de Flores com Machine Learning

  Projeto que implementa um modelo de Inteligência Artificial para classificar espécies
da flor Iris(Setosa, Versicolor e Virginica) com base nas medidas de suas pétalas e 
sépalas da flor.
  O objetivo é aplicar os meus conhecimentos sobre o funcionamento do algoritmo de suporte
à decisão e sobre o SVM(Support Vector Machine).

###Tecnologias Ultilizadas
* Python
* Scikit-Learn
* Pandas
* Matplotlib & Seaborn
